# X-VARS RAG功能使用说明

## 概述

X-VARS现在集成了RAG（检索增强生成）功能，能够基于知识库提供更准确、更可靠的回答。RAG系统会从预先构建的知识库中检索相关信息，然后结合这些信息生成回答。

## 功能特点

### 🔍 智能检索

- 基于语义相似度的文档检索
- 支持多种文档格式（TXT、MD、JSON）
- 可配置的检索参数（top-k、相似度阈值）

### 📚 知识管理

- 文档上传和管理界面
- 手动添加文本内容
- 知识库统计和监控
- 支持批量导入

### 🤖 增强对话

- 自动检索相关上下文
- 基于知识库的回答生成
- 可选的RAG开关控制

## 安装依赖

首先安装RAG功能所需的依赖包：

```bash
pip install langchain==0.1.0
pip install langchain-community==0.0.10
pip install faiss-cpu==1.7.4
pip install chromadb==0.4.22
pip install sentence-transformers==2.2.2
pip install openai==1.3.0
pip install tiktoken==0.5.2
```

## 启动系统

使用RAG增强版本启动X-VARS：

```bash
python x_vars_demo_with_rag.py
```

## 使用流程

### 1. 初始化知识库

#### 方法一：上传文件

1. 切换到"知识管理"标签页
2. 选择"文件上传"子标签
3. 点击"选择文件"上传文档
4. 点击"上传文档"按钮
5. 查看上传结果和统计信息

#### 方法二：手动添加

1. 切换到"添加文本"子标签
2. 在文本框中输入内容
3. 可选：添加标题和来源
4. 点击"添加文本"按钮

### 2. 使用RAG功能

#### 启用RAG

1. 在"视频聊天"标签页中
2. 展开"Parameters"设置
3. 勾选"启用RAG"
4. 调整"RAG检索文档数量"

#### 开始对话

1. 上传视频文件
2. 等待处理完成
3. 输入问题
4. 系统会自动检索相关知识并生成回答

### 3. 管理知识库

#### 搜索文档

1. 切换到"搜索文档"子标签
2. 输入搜索关键词
3. 调整返回结果数量
4. 点击"搜索"查看结果

#### 监控统计

1. 查看各标签页的统计信息
2. 在"RAG设置"中查看详细统计
3. 定期刷新状态信息

## 配置说明

### RAG系统参数

在 `rag_system.py`中可以调整以下参数：

```python
# 嵌入模型
embedding_model_name = "sentence-transformers/all-MiniLM-L6-v2"

# 向量存储路径
vector_store_path = "vector_store"

# 最大上下文长度
max_context_length = 2048

# 默认检索文档数量
top_k = 5
```

### 文档分割参数

```python
# 文档块大小
chunk_size = 1000

# 块重叠大小
chunk_overlap = 200
```

## 示例用法

### 1. 构建专业领域知识库

```python
# 添加技术文档
documents = [
    {
        "content": "深度学习在计算机视觉中的应用...",
        "metadata": {
            "title": "深度学习技术",
            "source": "技术手册",
            "category": "AI技术"
        }
    }
]

rag_system.add_documents(documents)
```

### 2. 批量导入知识

```python
# 从JSON文件导入
rag_system.add_json_file("knowledge_base.json", content_key="content")
```

### 3. 搜索相关知识

```python
# 检索相关文档
docs = rag_system.retrieve_relevant_documents("什么是深度学习？", top_k=3)
```

## 故障排除

### 常见问题

1. **RAG系统初始化失败**

   - 检查依赖包是否正确安装
   - 确保有足够的磁盘空间
   - 检查网络连接（首次下载模型）
2. **文档上传失败**

   - 检查文件格式是否支持
   - 确保文件编码为UTF-8
   - 检查文件大小是否过大
3. **检索结果不准确**

   - 调整top_k参数
   - 优化文档分割参数
   - 检查知识库内容质量
4. **系统运行缓慢**

   - 减少检索文档数量
   - 使用更小的嵌入模型
   - 优化硬件配置

### 日志查看

系统日志保存在 `gradio_web_server.log`文件中，可以查看详细的运行信息：

```bash
tail -f gradio_web_server.log
```

### 2. 参数调优

### 3. 硬件配置

- 使用GPU加速嵌入计算
- 增加内存容量
- 使用SSD存储

使用多语言嵌入模型支持多语言知识库。

### 3. 实时更新

可以实现知识库的实时更新和增量学习。
