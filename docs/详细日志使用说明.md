# 详细日志使用说明

## 📋 概述

系统已启用详细的生成日志记录功能，帮助您诊断模型回复"牛头不对马嘴"的问题。每次对话生成后，系统会自动保存详细的调试信息到日志文件。

## 📁 日志文件位置

所有详细日志保存在 `detailed_logs/` 目录下，包含两种格式：

1. **JSON格式** (`generation_log_YYYYMMDD_HHMMSS_微秒.json`)
   - 结构化数据，便于程序分析
   - 包含所有原始数据

2. **文本格式** (`generation_log_YYYYMMDD_HHMMSS_微秒.txt`)
   - 人类可读格式，便于直接查看
   - 包含完整的问题、prompt、输出等信息

## 📊 日志内容说明

### 1. 用户原始问题
- 记录用户输入的原始问题

### 2. RAG状态和检索结果
- RAG是否启用
- 检索到的所有相关规则（Top 3）
- 每条规则的相似度分数
- 实际使用的知识上下文

### 3. 增强后的问题
- 包含RAG检索结果的增强问题
- 用于生成的实际问题文本

### 4. 完整Prompt（包含视频token）
- **完整Prompt内容**：包含所有特殊token的完整提示词
- **Prompt长度**：字符数和token数
- **视频Token部分**：视频特征token的数量和位置
- **特殊Token分析**：VID_START、VID_END、VIDEO_PATCH的数量

### 5. 视频特征信息
- 特征张量的形状、数据类型、设备
- 特征的统计信息（最小值、最大值、均值、标准差）

### 6. 模型参数
- `video_token_len`: 视频token长度
- `temperature`: 生成温度
- `max_new_tokens`: 最大生成token数
- `do_sample`: 是否使用采样
- `use_rag`: 是否使用RAG

### 7. 模型原始输出
- 模型生成的原始文本（未清理）

### 8. 最终返回的输出
- 经过清理和处理的最终输出

## 🛠️ 如何使用日志诊断问题

### 问题1: 模型回复与问题不相关

**检查点**：
1. 查看"用户原始问题"和"增强后的问题"是否一致
2. 检查RAG检索结果是否相关（相似度分数）
3. 查看完整Prompt，确认问题是否被正确包含
4. 检查视频特征是否正常（统计值是否合理）

**可能原因**：
- RAG检索到错误的规则
- Prompt构建有问题
- 视频特征异常

### 问题2: 模型回复不完整

**检查点**：
1. 查看"生成统计"中的实际生成tokens数
2. 检查是否因为达到max_new_tokens限制而提前结束
3. 查看"模型原始输出"和"最终输出"的差异

**可能原因**：
- max_new_tokens设置太小
- 遇到停止词提前结束
- 输出清理过程删除了重要内容

### 问题3: 模型回复质量差

**检查点**：
1. 查看RAG检索到的知识上下文是否相关
2. 检查temperature参数是否合适
3. 查看生成的Token序列是否有异常模式
4. 检查视频特征的质量（均值、标准差是否正常）

**可能原因**：
- RAG知识库内容不匹配
- 生成参数设置不当
- 视频特征提取有问题

### 问题4: 模型回复重复或循环

**检查点**：
1. 查看生成的Token序列，检查是否有重复模式
2. 检查停止词设置是否正确
3. 查看temperature和do_sample参数

**可能原因**：
- 停止词未正确识别
- temperature太低导致重复
- 模型陷入循环生成

## 📝 日志分析示例

### 示例1: 检查Prompt是否正确

打开文本格式日志，查看"4. 完整Prompt"部分：

```
完整Prompt内容:
================================================================================
<用户问题>

参考规则：<RAG检索到的规则>

请简洁回答：

<VID_START><VIDEO_PATCH>...<VID_END>
================================================================================
```

确认：
- 用户问题是否完整
- RAG规则是否相关
- 视频token是否正确插入

### 示例2: 检查生成过程

查看控制台日志中的生成统计：

```
[GEN] 实际生成tokens: 45/64
[GEN] 生成时间: 12.34s
[GEN] 生成速度: 3.6 tokens/s
[GEN] 结束原因: 遇到停止词或EOS token
```

如果生成tokens数远小于max_new_tokens，可能是：
- 模型提前结束（遇到停止词）
- 需要检查停止词设置

## ⚙️ 配置选项

在代码中可以调整以下配置：

```python
# 详细日志配置
DETAILED_LOG_DIR = "detailed_logs"  # 日志保存目录
ENABLE_DETAILED_LOGGING = True  # 是否启用详细日志
```

## 💡 建议

1. **定期清理日志**：日志文件会不断累积，建议定期清理旧日志
2. **对比分析**：对比正常回复和异常回复的日志，找出差异
3. **关注关键指标**：
   - RAG相似度分数（应该>0.3）
   - 生成tokens数（应该接近max_new_tokens）
   - 视频特征统计值（应该在合理范围内）

## 🔧 故障排查

### 日志文件未生成

1. 检查`ENABLE_DETAILED_LOGGING`是否为`True`
2. 检查`detailed_logs/`目录是否有写入权限
3. 查看控制台是否有错误信息

### 日志内容不完整

1. 检查是否有异常中断
2. 查看控制台错误日志
3. 确认所有依赖都已正确安装
